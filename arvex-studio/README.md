# ARVEX STUDIO

فروشگاه نمایشی فارسی برای خدمات طراحی و چاپ؛ شامل دسته‌بندی، جستجوی محصولات، سبد خرید اولیه و پشتیبانی روبیکا.

## انتشار در GitHub Pages
1. یک مخزن با نام `arvex-studio` بسازید.
2. فایل `index.html` را در ریشه مخزن بارگذاری کنید.
3. به `Settings` → `Pages` بروید.
4. در بخش `Build and deployment`، گزینه `Deploy from a branch` را انتخاب کنید.
5. شاخه `main` و پوشه `/(root)` را انتخاب و `Save` کنید.
6. پس از چند دقیقه، آدرس سایت در همان بخش Pages نمایش داده می‌شود.
